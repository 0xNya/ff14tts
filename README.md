# ff14tts — TextToTalk → VOICEVOX Bridge

[![Go Version](https://img.shields.io/badge/Go-1.26+-00ADD8?logo=go)](https://go.dev)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

Бесплатный голосовой движок для **FINAL FANTASY XIV**. Перехватывает реплики NPC из плагина [TextToTalk](https://github.com/karashiiro/TextToTalk) и озвучивает их через [VOICEVOX](https://voicevox.hiroshiba.jp/) — японский TTS-движок.

<!-- (screenshot placeholder) -->

## ✨ Возможности

- **Озвучка NPC в реальном времени** — реплики появляются и озвучиваются через 1–3 секунды
- **Разделение на предложения** — длинные фразы разбиваются по `。！？` и синтезируются параллельно
- **Стриминг аудио** — первое предложение играется сразу, остальные догружаются в фоне
- **Веб-интерфейс** — не требует CGO/GCC, открывается в браузере (localhost:8080)
- **Чат-лог** — история сообщений с именами NPC, полом и таймстемпами
- **Кнопка повтора** — можно переозвучить любое сообщение

> **Не требует** установки дополнительных библиотек, C-компилятора или фреймворков.  
> **Один бинарник** — скачал и запустил.

## 📋 Системные требования

## 🚀 Быстрый старт

### 1. Скачать бинарник

[⬇️ Releases](https://github.com/0xNya/ff14tts/releases) — скачайте последнюю версию для вашей ОС.

### 2. Запустить VOICEVOX

Скачайте и запустите [VOICEVOX](https://voicevox.hiroshiba.jp/).  
Убедитесь, что Engine доступен на `http://localhost:50021`.

### 3. Настроить TextToTalk

В игре откройте настройки плагина **TextToTalk**:
- **Enable WebSocket Server** → ✅ включено
- **Port** → `5000` (по умолчанию)

### 4. Запустить ff14tts

```powershell
.\ff14tts.exe
```

Откройте в браузере: **http://localhost:8080**

### Сборка из исходников

```powershell
git clone https://github.com/0xNya/ff14tts.git
cd ff14tts
go build -o ff14tts.exe .
.\ff14tts.exe
```

## 🔧 Как это работает (технические детали)

### Поток обработки одного сообщения

1. **TextToTalk** отправляет JSON по WebSocket:
   ```json
   {
     "Type": "Say",
     "Speaker": "NPC名",
     "Payload": "本文。続き！",
     "Voice": { "Name": "Male" }
   }
   ```
2. **ff14tts** парсит сообщение, определяет категорию (Male → male)
3. **Разделение на предложения** — текст режется по `。！？…`
4. **Параллельный синтез** — каждое предложение отправляется в VOICEVOX одновременно (макс. 3 конкурентных запроса)
5. **Стриминг** — как только готово первое предложение — сразу проигрывается, остальные подгружаются во время озвучки
6. **Чат-лог** — сообщение и тайминги отправляются в браузер через SSE и polling

### Почему VOICEVOX может быть медленным?

VOICEVOX Engine обрабатывает запросы **последовательно** — параллельные запросы от ff14tts ставятся в очередь. Скорость синтеза напрямую зависит от мощности CPU и версии VOICEVOX:

| Конфигурация | Примерное время на предложение |
|-------------|-------------------------------|
| CPU (без GPU) | 3–8 секунд |
| CPU + GPU (CUDA) | 0.5–2 секунды |
| VOICEVOX + CoreML (Apple Silicon) | 0.3–1 секунда |

Рекомендуется использовать сборку VOICEVOX с поддержкой GPU (CUDA / CoreML).

## 📁 Структура проекта

```

├── main.go           # Точка входа, запуск всех компонентов
├── config.go         # Загрузка/сохранение config.json
```
